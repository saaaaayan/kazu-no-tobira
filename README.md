# 数のトビラ

**「子どもが、ひとりで学べる。」** を最上位設計原則とし、幼児・小学1年生〜高校3年生・賢者・覇王・宇宙の**全16島**を冒険しながら算数・数学を学べるアプリ。

学習者が問題を解けないときにも、段階ヒント・わかりやすい解説・前提単元への戻り方・類題を自分で選び、親や先生が隣にいなくても学習できることを目指す。詳細は[教育理念・教材品質](docs/EDUCATIONAL_PRINCIPLES_AND_QUALITY.md)。

## コンセプト
ひとつ解くたび、世界がひらく。

## 開発方針
- Web・Android・iOS対応
- 問題の品質を最優先
- 苦手克服・個別最適化学習
- Codexによる開発

## 開発環境

- Node.js 24.11 以降
- pnpm 11.25.0
- Expo SDK 58 / React Native / TypeScript

```sh
pnpm install --frozen-lockfile
pnpm web
```

Expo が表示したローカル URL（既定では http://localhost:8081）を開きます。
同じコードを端末で開くには `pnpm start` を使います。ローカルの Android
エミュレーターは `pnpm android`、macOS の iOS シミュレーターは `pnpm ios` で起動できます。

```sh
pnpm test
pnpm typecheck
pnpm build:web
```

## 現在の開発段階と完成目標

- **試作版**：代表的な島・問題形式を、サンプル専用プレビューで動作確認する。実教材・正答・個人情報を公開静的バンドルに載せない。
- **知人向け限定β版**：16島×65ステージに**各10問＝10,400問**を品質審査して配置する。各島の冒険の道50ステージは5ステージごとに確認テスト（計10回）。試練の道10と伝説のトビラ5も含む。
- **一般公開版**：各ステージ100問＝**104,000問**を目標に、学習支援・利用権・安全な決済・運用を完成させる。

学年別の単元と出題内容を合わせ、**問題・ヒント・解答・解説を数学的および教育的に審査したものだけ配信**する。実装状況は [開発ロードマップ](https://github.com/saaaaayan/kazu-no-tobira/issues/62) と[全島のステージ構成](docs/STAGE_STRUCTURE_AND_NAMES.md)を参照する。
