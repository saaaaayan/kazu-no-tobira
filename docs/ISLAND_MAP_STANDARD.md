# 島マップ共通デザイン仕様 — 確定（2026-11-21）

## 最上位原則
幼児「ぬいぐるみの島」の完成レイアウトを、今後の全16島の共通テンプレートとする。**新しい島ごとにルート、余白、看板、配置、UIを作り直さない。** 子どもがひとりで使えることを最優先する。

## 全島共通の骨格
- 最初に見えるのは世界地図へ戻るリンク、短い案内、マップ本体。試作・開発情報、カリキュラム、スタート案内はマップの下に置く。
- 上部タイトルは学年＋島名。小さなピクセルスタンプを左右につける。大型バナーは不要。
- 65地点を5地点×13行の蛇行する一本道に置く。通常50、試練10、伝説5の構成と区切りを保持。
- 5ステージごとに10か所の確認テスト看板。ルートの縦つなぎ部の空き地に配置し、対象範囲も表示。
- 丸いステージ番号をタップすると出題へ。番号の下には短い学習名。学習名をタップするとステージの説明カード。
- 幼児のマップ座標関数、確認看板座標関数、ステージラベル座標関数を変更せず共有する。スマホも同じルール。
- 装飾は衝突判定済みの領域だけに置き、番号・名称・通路・看板・タイトルを妨げない。

## 表現
- ファミコン風8-bit、少数の落ち着いた色、幾何学的なアイコン。キラキラ、グラデーション、派手な色は禁止。
- **経路・ノード・看板の位置と大きさ**は全島同じ。地形・海・道・帯模様・エリア背景の色は島のイメージに合わせて変える。色まで全島統一して黄緑だけにしない。
- テーマごとに変えるものは島名、学年名、タイトルの小さな装飾印、背景色、地面色、道の色、各島を象徴するドット絵。機械的な整列装飾をしない。
- 幼児は従来どおり淡黄緑の草原。**小1おもちゃの島は、青い海＋コーラル／ベージュの木製おもちゃの世界**。この2島は明確に違う色相。

## リリースチェック
1. 全16島の65地点、10看板、3区分が座標・寸法・スクロール規則まで一致すること
2. 全16島の配色を区別し、幼児の既存描画が変わらず、小1は草原でなくコーラル・ベージュの木製おもちゃ色であること
3. 装飾がラベルやステージ、看板、ルートを隠さないこと
4. 最初に地図が見え、余計なカードが上に積まれていないこと
5. 丸ノードのステージ遷移、タイトルの説明カード、確認テスト、世界地図へ戻る導線が機能すること
6. 小1の通常50地点は個別のカリキュラムに合致し、全島でEX・隠しも保持すること。未制作の問題は「準備中」を維持すること
7. 問題・解答・ヒント・解説・審査データは地図改修で変更しないこと

将来の全島に上記の基本レイアウトを継承する。
