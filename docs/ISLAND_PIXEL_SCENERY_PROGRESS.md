# 16島のピクセル背景改修

## 実装

ステージ座標、65地点、10確認テスト、ラベル、看板、操作は既存の共通配置を使用する。
世界地図の承認済み画像、教材、課金条件、セーブは今回の変更対象に含めない。

- 絵柄は `islandPixelSprites.ts` の共通アトラスで管理する。168種のうち今回の新規IDは128種。既存IDの木・山・火山・恐竜・城・工場も描き直した。
- 各島に大3種、中7種、小8種の18モチーフと地面模様4種を登録。幼児の23種のぬいぐるみ、小1のおもちゃの既存描画を維持し、空き地に追加する。登録数と実際の表示数は区別する。
- `islandScenery.ts` が固定シードで配置し、既存と同じ除外領域を使って番号・文字・道・確認看板との接触を避ける。同じモチーフを近接配置しない。
- 迷宮は島全体の格子で深さ優先探索し、曲がり角・分岐・袋小路を持つ石壁を描く。攻略ルートと文字の領域は壁を切り抜き、装飾の下も空ける。壁の描画は二つのSVGパスに集約する。
- 地面の表現と大中小の絵柄を独立した層にする。登録の追加でステージ配置を変更する必要はない。

## 検証・再開地点

- 自動検査は244〜1220pxの10マップ幅で全16島を検査。配置不変、壁・装飾・地面のUI非干渉、同種の距離、描画データと固定シードの再現性を対象にする。
- 308件のテスト、型チェック、Webビルドが合格。
- 公開サイトでの全16島と320/375/430px・PCのスクリーンショット確認、必要な修正、最終SHA照合を続ける。実画面未確認の段階で見た目の品質を承認済みと扱わない。
