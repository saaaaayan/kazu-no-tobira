# 数のトビラ｜正式メインキャラクター「オイラー」デザイン基準

> **暫定正式採用日：2026-11-22。** ユーザーが、直近に制作した深緑×金色のキャラクターと黒いシルエットを「一旦正式メインキャラクターとして登録」と指定。これは**キャラクター設定・デザインの承認**であり、ゲーム画面への実装・画像アセット登録の完了を意味しない。

## 1. 基本設定

- **名称：オイラー（Euler）**
- **位置づけ：**「数のトビラ」の正式メインキャラクター／数学の世界を旅する主人公、数学の冒険家。
- **モデル：** 数学者レオンハルト・オイラー（Leonhard Euler, 1707–1783）。
- **デザインモチーフ：** オイラーの公式から得られる恒等式 **\(e^{i\pi}=-1\)** （同値な表現：\(e^{i\pi}+1=0\)）。
- **世界観：** 子どもから高校生まで親しめる、知的で勇敢なファンタジーの冒険家。ファミコン風の明瞭なピクセルアートを基本とする。
- **既存のルミとは別の役割：** オイラーが主人公。ルミは既存の学習支援／案内役。既存のルミのゲーム内実装はこの登録のみで変更しない。

## 2. 採用する外見（変更時はユーザー確認）

- **配色：** ネイビーブルー主体ではなく、落ち着いた**深緑／フォレストグリーン**主体。**金色**の縁取り・記号、**クリーム色**の服、**茶色**のブーツ・小物。髪は**銀色〜薄灰色**、瞳は**青**。
- **帽子：** 大きな柔らかいとんがり帽子。深緑に金の縁取り、**正面に金色の小文字 e**。白い羽飾り。
- **マント：** 深緑＋金の縁取り。**大きな金色の π** を入れ、後ろ姿でも識別できること。
- **ポーチ：** 腰の茶色いポーチに金色の **i**。
- **杖：** 木製の杖の先端に大きな**∞（無限大）**の金色の装飾。
- **その他：** クリーム色のチュニック、緑の宝石の留め具、ベルト、茶色のブーツ。親しみやすいデフォルメ体形。
- 記号は**帽子 e ／ポーチ i ／マント π ／杖 ∞**に分散させる。公式全体を衣装の全面に繰り返し配置した派手な案は採用しない。
- 過度にキラキラさせず、数種類の色で見分けやすい姿を維持する。

## 3. 公式シルエット

- カラーキャラクターと**完全に同一の帽子・羽飾り・マント・杖・体形の輪郭**を使用する。
- 黒または黒に近い単色のシルエットで、**顔・服の内側の色は出さない**。小さくても **帽子＋羽＋∞の杖＋なびくマント** で識別できること。
- トップページの「数学のトビラの前に立つ冒険家」は、この**オイラー本人のシルエット**とする。別人物のシルエットに差し替えない。
- e / i / π はカラー版の主要記号。シルエット版では小サイズで可読性が下がるなら省略可（輪郭が優先）。

## 4. 表示用素材・制作ルール

- **設定画：** 立ち絵、正面、横、後ろ、喜び・考える等の表情。
- **ゲーム用：** 粗さ違いのドット絵、低解像度スプライト、歩行アニメーション。
- **ロゴ／タイトル用：** 同一人物を真っ黒のシルエットにして利用。
- 既存の会話で生成した**深緑版のキャラクター設定画およびオイラーの黒シルエット案**がビジュアル参照。現時点では画像そのものはリポジトリに未格納で、GitHubの正式ゲームアセットとしては別途登録が必要。
- レイアウト・縮小率を変えても e/i/π/∞ の位置関係を維持する。数学記号の表記を誤らない。
- 教材の採点・進捗データ・島の構成・既存のキャラ表示をこの文書登録だけで変更しない。
