# 数のトビラ：全104,000問制作・継続実行の最上位ルール

## 全体の完成条件（2026-11-16）
- 最終設計：全16島（幼児、小1〜高3の12島、賢者、覇王、宇宙）。
- 1島65ステージ（通常50、EX10、隠し5）×16＝1,040ステージ。
- 各ステージ専用の良質な100問＝**104,000問**を目標とする。
- 既存の13島・845ステージ・84,500問という古い目標を、最終目標として使わない。
- 学習上必要な反復は許容するが、数字や題名を入れ替えただけの同型大量生産、文面だけの言い換え、他学年と隠しステージ間の同一固定問題の再利用で「独立した良問数」を水増ししない。
- 問題は単元、学習目標、出題形式、難易度、技能、採点条件、正答、基本解説、詳しい解説、必要な図形・グラフ、検算手順とレビュー状態を持つ。単元別の説明と問題に整合性があること。
- 出題形式を計算・文章読解・条件整理・図形・表/グラフ・選択・複数選択・式・穴埋め・並べ替え・反例・誤り指摘・証明・作図・操作などに拡張。文字だけ／図だけ／文字と図の統合を教育目的で使い分ける。
- 図やグラフに必要な条件が欠けた問題、誤答、未検証の解説は完成とは数えない。形式的な自動テストだけでは教育的品質レビューを完了としない。
- 10万問以上の配信可能な品質確認済み教材が実際に存在するまで「全10万問収録」と宣伝しない。

## Codexの作業継続に関する必須ルール
1. ユーザーからの依頼は **全104,000問の制作** であり、特定の24ステージの修正や1,920問のテスト生成で終了してよいという意味ではない。
2. 自分の判断で全体の依頼を局所タスクへ**縮小・完了扱いしない**。処理を小さなPRや学年単位に分割することは可。ただし全体ゴールは常に未完了として保持。
3. 実行冒頭にmainの現状・Issue #37/#39/#41・進捗ファイルを読み、次に未完了の学年・ステージ・単元を特定する。特定の得意分野だけに偏らず全領域の網羅を追跡する。
4. 利用可能な実行枠内で、質の良い教材の制作・検証・mainへの安全な統合・確認用Web反映をできる限り進め、完了した分を正確に報告する。その後も次の未完成範囲に着手する。
5. 制限・障害で処理の継続が不可能になる場合は、進捗・最後に完了したステージ・未完成範囲・次に実行する指示を**リポジトリに永続保存**。全体を「完成」と呼ばない。
6. 次回のCodex実行では、この進捗ファイルを読むだけで自動的に作業を再開できるようにする。ユーザーに毎回最初から説明を求めない。
7. Codexの1回の作業で10万問の教育品質確認が終わると約束しない。セッション制限を無視した無限実行・自動復帰もできると主張しない。

- 全体目標：104,000問・1,040ステージ
- 専用問題の累計登録数と今回の増分：数値を実測
- 数学的検証済み数、教育的レビュー済み数、公開可能数、ボツ数（不明なら不明）

- 次回の開始ステージ・残り問題数
- テスト結果、マージしたPR、確認用WebのURLと実ブラウザー確認状況
- 全体の状態：全条件を満たすまで **未完成**
