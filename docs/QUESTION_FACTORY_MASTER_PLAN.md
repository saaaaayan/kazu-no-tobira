# 数のトビラ：全104,000問制作・継続実行の最上位ルール

## 全体の完成条件（2026-11-16）
- 最終設計：全16島（幼児、小1〜高3の12島、賢者、覇王、宇宙）。
- 1島65ステージ（通常50、EX10、隠し5）×16＝1,040ステージ。
- 各ステージ専用の良質な100問＝**104,000問**を目標とする。
- 既存の13島・845ステージ・84,500問という古い目標を、最終目標として使わない。
- 学習上必要な反復は許容するが、数字や題名を入れ替えただけの同型大量生産、文面だけの言い換え、他学年と隠しステージ間の同一固定問題の再利用で「独立した良問数」を水増ししない。
- 問題は単元、学習目標、出題形式、難易度、技能、採点条件、正答、基本解説、詳しい解説、必要な図形・グラフ、検算手順とレビュー状態を持つ。単元別の説明と問題に整合性があること。
- 出題形式を計算・文章読解・条件整理・図形・表/グラフ・選択・複数選択・式・穴埋め・並べ替え・反例・誤り指摘・証明・作図・操作などに拡張。文字だけ／図だけ／文字と図の統合を教育目的で使い分ける。
- 図やグラフに必要な条件が欠けた問題、誤答、未検証の解説は完成とは数えない。形式的な自動テストだけでは教育的品質レビューを完了としない。
- 10万問以上の配信可能な品質確認済み教材が実際に存在するまで「全10万問収録」と宣伝しない。

## Codexの作業継続に関する必須ルール
1. ユーザーからの依頼は **全104,000問の制作** であり、特定の24ステージの修正や1,920問のテスト生成で終了してよいという意味ではない。
2. 自分の判断で全体の依頼を局所タスクへ**縮小・完了扱いしない**。処理を小さなPRや学年単位に分割することは可。ただし全体ゴールは常に未完了として保持。
3. 実行冒頭にmainの現状・Issue #37/#39/#41・進捗ファイルを読み、次に未完了の学年・ステージ・単元を特定する。特定の得意分野だけに偏らず全領域の網羅を追跡する。
4. 利用可能な実行枠内で、質の良い教材の制作・検証・mainへの安全な統合・確認用Web反映をできる限り進め、完了した分を正確に報告する。その後も次の未完成範囲に着手する。
5. 制限・障害で処理の継続が不可能になる場合は、進捗・最後に完了したステージ・未完成範囲・次に実行する指示を**リポジトリに永続保存**。全体を「完成」と呼ばない。
6. 次回のCodex実行では、この進捗ファイルを読むだけで自動的に作業を再開できるようにする。ユーザーに毎回最初から説明を求めない。
7. Codexの1回の作業で10万問の教育品質確認が終わると約束しない。セッション制限を無視した無限実行・自動復帰もできると主張しない。

## 全16島のカリキュラム・世界設計（Issue #39 の詳細を最上位仕様へ統合）

**島とステージの順序**
1. 幼児の島：数の概念の入口。タップして具体物を1個ずつ数える、数と数字の対応、数字の読み・なぞり書き・書字、数の大小・並び、仲間分け、形・色・簡単な規則性。読字能力を前提にせず大きなタッチ領域、視覚・音声案内、誤操作に寛容な操作を提供。手書き認識が曖昧なとき誤答扱いしない。
2〜13. 小学1年〜高校3年の各12島：学習指導要領の学年別単元を網羅。無料の単元別学習で「理解する→例題→理解確認→対応するステージ」の順に進む。学年をまたぐ前提技能の対応表、問題形式の多様性、学習の発達段階に合う難易度を重視する。
14. 賢者の島：高校数学の複数分野を横断する入試総合・難関大学入試レベル。単なる同種計算の難度上げでなく分野を組み合わせる。
15. 覇王の島：高校範囲の知識を主軸に、超難関大学入試・数学オリンピック級の発想力、場合分け、論証、反例、不等式・整数・幾何・組合せなど。
16. 宇宙ステージ：大学数学と高度な探究。線形代数、解析学（厳密な極限・級数・微積分）、数論、確率論・ランダムウォーク、微分方程式、集合・論理、幾何など。新概念は学習ページで定義や例を学んでから出題。証明・反例・理論のつながりも扱う。

**全体ボリュームの設計値**
- 原則各島65ステージ：通常50・EX10・隠し5。16島合計1,040ステージ。
- 原則各ステージの専用問題バンク100問。合計**104,000問（最終目標）**。一回の攻略は原則10問。バンク内の100問は原則異なる良質な問題とする。
- 幼児向けの意味のある活動量に合わせてステージ・形式を調整する必要が生じたら、総104,000問の教材品質を損なわない配分案を別途整理し、承認なしに数量水増しで帳尻を合わせない。
- 一般告知「全10万問以上収録」は、内容・答え・解説・必要な図が検証済みで、実際に配信可能な問題が100,000件以上存在してからのみ使用する。

**既定の課金区分**
- 決定済み：小1〜高3の通常50×12=600ステージと単元別の基礎学習は無料。各学年のEX/隠し、賢者の島、詳しい問題解説、弱点分析・原因診断・克服問題、毎日15分学習、定期復習、成長レポートは有料。
- 追加3島については**提案**：幼児の島の通常50ステージ無料・EX/隠し有料、覇王の島と宇宙ステージは全ステージ有料。まだ最終確定していないため、本番課金処理へ無断で固定しない。
- 開発中は無料／有料ユーザーを切替可能。本番でローカル切替やフロントエンドだけの課金判定に依存しない。

**学習・出題の詳細**
- 文章だけから条件を読み解く問い、図だけを観察する問い、文章と図を統合する問いを混ぜ、自力で方針を立てる力を育てる。
- 数値・数式入力、単一/複数選択、表/グラフ、空欄補充、並べ替え、作図・操作、条件整理、規則性、誤り発見、反例、論証・証明など多形式を用意。自由記述・証明の評価を未検証の自動正答判定で装わない。
- 隠しステージは他学年で同じ問題を使い回すのではなく、数の不思議・発見・探究の独自問題を中心にする。
- 登録数・生成可能数・正答検証済み数・教育レビュー済み数・公開準備完了数を混同しない。

## 管理者専用「全問題一覧・品質審査」仕様（Issue #41 の詳細を最上位仕様へ統合）

**画面と操作**
1. 全16島・全1,040ステージで確定IDを持つ登録問題を漏れなく一覧できる。将来の10万問規模でも毎回全件を端末へロードせず、サーバー検索・ページングで高速に検索する。
2. 学年・島・単元・ステージ（通常/EX/隠し）・出題形式・技能・難易度・図あり/図なし・審査状態・重複疑いなどのフィルタ、問題文・答え・解説・IDの横断検索を提供する。
3. 問題を選択すると、生徒側と同じ数式・図形・グラフ描画を用いた出題プレビューに加え、正解（別解・許容表記）、採点条件、基本解説、詳細解説、ヒント、誤答の原因、単元リンクを確認できる。
4. ステータスは**未確認 → 要修正 → 確認済み → 公開準備完了**および**ボツ**。必要に応じて再審査・差戻し・状態変更が可能。現在状態は一覧で視覚的に識別しやすい色・テキストを両方併用する。
5. 問題不成立、意味が曖昧、正答が誤り、解説が誤り/不十分、図・グラフ不足、重複、難度・単元不適合などのボツ理由を選び、修正指示やコメントを保存する。
6. 審査日時、審査者、旧版と改訂版、変更前後の状態を監査履歴に残す。複数選択・一括審査、CSV/JSON出力、ステージごとの制作・審査件数と不足数を可視化する。
7. ボツを含む不適切問題は削除して履歴を失うのでなく「出題対象外」として管理する。公開準備完了以外は一般ユーザーへの出題不可。公開準備完了から他状態に戻したら速やかに非公開になる。

**本番システムの絶対条件**
- 管理者本人しか審査・修正できないサーバー認証／ロール検証を行う。開発版の隠しリンク・端末フラグを認可とみなさない。
- 専用の問題データベース、問題バージョン、審査履歴、公開状態、公開判定のサーバーAPIを設計し、一般ユーザーと管理者のアクセスを分離する。既存の無関係なアスカ見参用Supabase DBを流用しない。
- 生徒向けの通常ステージ、有料ステージ、15分個別学習、復習、診断、テスト出題など**すべての選出経路**はサーバーの公開可能判定を共通利用し、管理者のボツを即座に反映する（既存学習履歴は保持）。
- 未公開教材・有料コンテンツの問題本文と答えを一般公開の全件JSONやアプリバンドルから読み取れないようにする。
- バッチ作問の問題が管理画面に即反映され、審査を経て初めて公開される一連のワークフローを実装する。

**現在の実装との区別**
- PR #42で実装・main統合済みの開発用初期版は、既存の専用問題バンク約4,300問に限定した閲覧・検索・ステータス・ボツ理由/メモ・CSV/JSON書出し機能。
- この初期版は __DEV__ のみに表示され、審査記録は端末内保存。管理者ログイン、共有DB、ボツの即時出題除外、未登録の自動生成問題の全件管理、10万問対応のサーバー検索は**未実装**。初期版を本番の管理機能完成と報告しない。
- 問題の内容に不備があっても管理者が直接改訂・再審査しやすい履歴管理・修正ワークフローを後続開発に含める。
