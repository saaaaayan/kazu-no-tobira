# 数のトビラ｜全16島共通ステージ区分・正式名称

正式決定：2026-11-16（ユーザー承認）。「冒険の道」の名称も同日追認。この仕様は幼児の島から宇宙ステージまで全16島に適用する。旧名称を記した資料とは、この仕様の正式表示名を優先する。

## 正式名称と内部互換性

| 正式な表示名称 | 1島の数 | 内部種別 | 既存IDの例 | 旧称 |
| --- | ---: | --- | --- | --- |
| **冒険の道** | **50** | `normal` | `preschool.n01` | 通常ステージ |
| 確認テスト | 10回 | 既存ステージ外の専用イベント | （未実装） | — |
| **試練の道** | **10** | `extra` | `preschool.x01` | EXステージ |
| **伝説のトビラ** | **5** | `secret` | `preschool.s01` | ひみつの道／隠しステージ |

- 全16島で新名称を統一する。地図、ステージ選択、攻略案内、称号、保護者画面、管理画面等のユーザー向け表示は**「冒険の道」「試練の道」「伝説のトビラ」**とする。
- **既存のステージID、内部 `kind='extra'` / `kind='secret'`、問題ID、データベース、セーブ、学習履歴、審査履歴は変更しない**。表示ラベルの変更のみ行う。
- 旧名称は移行・技術的な互換説明で「旧称」と明記した場合に限り使う。新規UIや教材の正式名称には採用しない。

## 攻略フロー

1. **冒険の道**の5ステージを攻略し、対応する確認テストを受ける。これを10エリア繰り返す（冒険の道50ステージ＋確認テスト10回）。
2. 発展・応用に挑む**試練の道（10ステージ）**を攻略する。
3. 冒険の道50＋試練の道10の**全60ステージをパーフェクトクリア**すると、**伝説のトビラ（5ステージ）**を解放する。

確認テストは**65ステージの内数ではない**。既存の冒険の道（内部 `normal`）のステージIDや番号を変更せず、将来別イベント・別攻略記録で実装する。テストの点数配分・合格基準・詳細な解放条件は未確定事項を勝手に確定させない。テストは直前の5ステージの問題を復習用に出題し、不必要な別問題を水増ししない。

## 規模・問題バンク

| 区分 | 1島 | 全16島 |
| --- | ---: | ---: |
| 冒険の道 | 50 | 800 |
| 試練の道 | 10 | 160 |
| 伝説のトビラ | 5 | 80 |
| **問題バンク対象ステージ** | **65** | **1,040** |
| 確認テスト（別枠） | 10 | 160 |
| 地図上の挑戦地点合計 | 75 | 1,200 |

教材制作目標は**全1,040ステージ×100問＝104,000問**のまま。確認テストで繰り返し出題した問題は新規収録問題数として数えない。教材審査・公開可否は従来の品質基準を適用する。

## 実装上の必須条件

- 世界地図・ステージ詳細・攻略条件・管理画面などの表示名を単一のラベル定義から統一し、旧称のUI露出をテストする。
- `normal` / `extra` / `secret` と既存の `.n` / `.x` / `.s` 系IDはそのまま使用する。`normal` は「冒険の道」の内部識別子であり、旧称「通常ステージ」の表示へ戻さない。名称変更をDB移行や課金変更の理由にしない。
- 確認テストを実装するときは既存の出題・公開判定・学習履歴を維持し、認証・課金権限はサーバーで検証する。
- この仕様書は**名称・構成の決定**であり、実アプリの画面表示切り替えがすでに完了したと意味しない。
