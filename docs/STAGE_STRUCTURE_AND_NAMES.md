# 数のトビラ｜全16島共通ステージ区分・正式名称

正式決定：2026-11-16（ユーザー承認）。「冒険の道」の名称も同日追認。この仕様は幼児の島から宇宙ステージまで全16島に適用する。旧名称を記した資料とは、この仕様の正式表示名を優先する。

## 正式名称と内部互換性

| 正式な表示名称 | 1島の数 | 内部種別 | 既存IDの例 | 旧称 |
| --- | ---: | --- | --- | --- |
| **冒険の道** | **50** | `normal` | `preschool.n01` | 通常ステージ |
| 確認テスト | 10回 | 既存ステージ外の専用イベント | （未実装） | — |
| **試練の道** | **10** | `extra` | `preschool.x01` | EXステージ |
| **伝説のトビラ** | **5** | `secret` | `preschool.s01` | ひみつの道／隠しステージ |

- 全16島で新名称を統一する。地図、ステージ選択、攻略案内、称号、保護者画面、管理画面等のユーザー向け表示は**「冒険の道」「試練の道」「伝説のトビラ」**とする。
- **既存のステージID、内部 `kind='normal'` / `kind='extra'` / `kind='secret'`、問題ID、データベース、セーブ、学習履歴、審査履歴は変更しない**。表示ラベルの変更のみ行う。
- 旧名称は移行・技術的な互換説明で「旧称」と明記した場合に限り使う。新規UIや教材の正式名称には採用しない。

## 攻略フロー

1. **冒険の道**の5ステージを攻略し、対応する確認テストを受ける。これを10エリア繰り返す（冒険の道50ステージ＋確認テスト10回）。
2. 発展・応用に挑む**試練の道（10ステージ）**を攻略する。
3. 冒険の道50＋試練の道10の**全60ステージをパーフェクトクリア**すると、**伝説のトビラ（5ステージ）**を解放する。

確認テストは**65ステージの内数ではない**。既存の冒険の道（内部 `normal`）のステージIDや番号を変更せず、別イベント・別攻略記録で実装する。テストの合格基準・詳細な解放条件は未確定事項を勝手に確定させない。確認テストは重複問題数の水増しをしない。

### 確認テストの出題とマップ配置（2026-11-16 ユーザー正式決定）

- 冒険の道の**5ステージごと**（05・10・15・20・25・30・35・40・45・50クリア後）に、**確認テスト**を1回配置する。計**10回／島、160回／全16島**。
- **必ず直前の5ステージの問題バンク**を母集団にし、そこから**ランダムに10問**選ぶ。1回のテスト内では同じ問題を重複させない。出題候補は中央審査で公開準備完了となった問題に限る。
- **マップの蛇行する道の折り返し（Uターン）部分**にテスト地点を置く。各列／段に冒険の道5ステージを並べ、行きと帰りの向きを交互にする。折り返しテスト後、次の5ステージへ進む。子どもに直感的に進行方向を伝える。
- 地図は全島共通のテンプレートで構成できるよう、折り返し方向・チェックポイント番号・5つの対象ステージIDをデータ化する。既存の通常ステージIDは並び順によって不規則なケースがあるため、数値文字列から出題対象を推測しない。
- 再挑戦時は同じ5ステージから再抽選できる。十分な問題が未登録・未審査の場合は別学年の問題や自動生成の未検証問題を補填せず、教材準備中として扱う。
- テストの合格点・不合格時の演出・採点方法は別途確定する。過去に提案した「8/10以上」や「確認テスト用に別の問題を追加制作」は正式決定事項ではない。

**蛇行マップ例（1島の冒険の道）**

```text
01 → 02 → 03 → 04 → 05 → [確認01]
                               ↓
[確認02] ← 10 ← 09 ← 08 ← 07 ← 06
     ↓
11 → 12 → 13 → 14 → 15 → [確認03]
                               ↓
      …（5ステージごとに交互に折り返す）…
                               ↓
[確認10] ← 50 ← 49 ← 48 ← 47 ← 46
```


## 規模・問題バンク

| 区分 | 1島 | 全16島 |
| --- | ---: | ---: |
| 冒険の道 | 50 | 800 |
| 試練の道 | 10 | 160 |
| 伝説のトビラ | 5 | 80 |
| **問題バンク対象ステージ** | **65** | **1,040** |
| 確認テスト（別枠） | 10 | 160 |
| 地図上の挑戦地点合計 | 75 | 1,200 |

教材制作目標は**全1,040ステージ×100問＝104,000問**のまま。確認テストで繰り返し出題した問題は新規収録問題数として数えない。教材審査・公開可否は従来の品質基準を適用する。

## 実装上の必須条件

- 世界地図・ステージ詳細・攻略条件・管理画面などの表示名を単一のラベル定義から統一し、旧称のUI露出をテストする。
- `normal` / `extra` / `secret` と既存の `.n` / `.x` / `.s` 系IDはそのまま使用する。`normal` は「冒険の道」の内部識別子であり、旧称「通常ステージ」の表示へ戻さない。名称変更をDB移行や課金変更の理由にしない。
- 確認テストを実装するときは既存の出題・公開判定・学習履歴を維持し、認証・課金権限はサーバーで検証する。
- この仕様書は**名称・構成の決定**であり、実アプリの画面表示切り替えがすでに完了したと意味しない。
