# 全16島・各65ステージの問題制作台帳（2026-11-18）

> **最優先：小学1年生だけではなく16島すべて。** この台帳は「既存問題を再作成せず、全ステージに10問以上の正答・3段階ヒント・基本/詳細解説・必要な図・操作を揃える」ための対象一覧です。**在庫の集計や問題生成関数の存在をもって、教材の制作・教育確認・公開完了と扱わない。**

## 確定範囲

16島の順序：幼児／小1／小2／小3／小4／小5／小6／中1／中2／中3／高1／高2／高3／賢者／覇王／宇宙。各島は10単元×冒険5ステージ、単元ごとの試練1ステージ×10、伝説5ステージ。

**計算方法**：各ステージについて `max(0, 10 - DB内有効問題数)` を算出し合計。小学1年の4,000問と賢者の300問は、それぞれ既存43ステージに100問ずつ集中している。100問のステージの余剰90問は、別ステージの不足を埋めたことにしない。4,323問中のその他23問は小1・賢者・覇王・宇宙・幼児の少数下書きであり、ステージごとに集計した。

**重要な区別**：幼児01〜05の公開試作問題（02〜05は10問ずつ）は、すべてがDB問題として登録されているわけではない。非公開原稿・試作サンプル・DB登録・教育的確認・一般配信は別の数字で管理し、重複加算しない。

全件のステージID・島・カテゴリ・技能・名称・制作ステータス・登録問題数・不足数は [1,040件のステージ台帳](ALL_16_ISLANDS_1040_STAGE_INVENTORY.tsv) を参照。元のDB内容は変更していない。

## カテゴリを確定する前の分類検査

- すべての島で冒険50を10単元×5ステージに割り当て、**学年と単元に合った問題だけ**を置く。冒険の5区間を「基礎→練習→理解→応用→まとめ」として段階的に難しくする。ただし汎用の道名だけを教材テーマの確定と見なさない。
- 各島の試練10はそれぞれの10単元に対応する発展課題。伝説5は数理の発見・探究・高難度課題として、通常問題の単純な数値差替えを禁止する。
- **幼児**：なぞり書き・絵と数の対応・並べ替えは専用操作UIが必要。選択肢だけの別問題に置き換えて「作成済み」としない。数字の理解と文字の書字は別技能。
- **小1〜小3**：学年でまだ読めない漢字、未習の計算や抽象説明を使わない。時計の問題では実際の時計の絵を必須にする。
- **小4〜小6**：単位・位取り・割合・図形など、図に表示した条件と解説の式を突き合わせる。
- **中学・高校**：式・図・条件・別解の論理を検査する。高校の数式、組合せ記号、証明の途中式を省略しすぎない。
- **賢者**：既存01〜03の100問は複数分野の横断問題なので、単一科目に誤分類しない。現状の後続「総合演習」ラベルは**カテゴリ細分化が必要**であり、汎用名だけで問題制作完了扱いしない。
- **覇王・宇宙**：数論・不変量・証明／大学数学・数列・線形代数・解析などの既存10単元を維持し、計算だけの安易な量産でテーマをすり替えない。
- 学習順序、具体的なサブカテゴリ名、内容の難易度は開発者の評価で調整可能。ステージIDと既存の進捗履歴は維持する。

## 本当に「10問作成済み」と数える条件

1. そのステージの目的に一致する独立した10問が**実データとして保存**されている。
2. 各問題に問題文／正答／3段階ヒント／基本解説／詳しい解説、必要な図と操作・正誤判定がある。
3. 数学的な正答を独立に検算し、図と数量・重複ID・重複問題・選択肢の正答数を検査する。
4. 操作を実ゲーム画面で再現できる。図形・時計・手書き・ドラッグ等の必要機能がない場合は要実装のままにする。
5. 以上を満たしたステージの **制作ステータス**を「10問作成済み」に進める。「制作者による確認済み」「100問作成済み」「制作者による最終確認済み」「子供によるテスト済み」は条件が別。

**進行方法**：全16島のカテゴリと不足をこの台帳で固定したうえで、学年／単元別に10問セットを制作し、ステージごとに保存・QA・実ゲームプレビューへ接続する。**現在の不足9,947問を、この台帳ができただけで完成と報告しない。**
