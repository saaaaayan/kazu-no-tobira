# 幼児（就学前）の問題文・ヒント・解説：品質基準

> 目的：**子どもが、ひとりで学べる。**
> 対象：ぬいぐるみの島の全65ステージ。問題・ヒント・正答・解説だけでなく、図と操作案内も確認する。
> 状態：作問およびレビュー時の必須チェックリスト。自動検査だけで教材の承認・公開準備完了にはしない。

## 最優先の6原則

1. **目に見えるものを、そのまま呼ぶ。** 画面に `□` があれば「□に はいる すうじは？」と聞く。「かくれた すうじ」「あいている ところ」などの遠回しな言い方は避ける。比喩は意味が分かるよう具体的な絵や説明を添えた場合のみ。
2. **ひとつの文で、ひとつの行動を伝える。** 「えらぼう」「さわろう」「かぞえよう」など、何をすればよいかがはっきり分かる短い言葉を使う。不要な連続指示や抽象語を避ける。
3. **問題文と絵と選択肢は一致させる。** 「おさらの りんご」と聞いたらお皿とりんごを表示する。空皿はゼロ個。まる・さんかく等は単なる記号ではなく、条件が分かるように表示する。
4. **正解を問題文で教えない。** 例えば「赤い丸を探そう」という問題で正解の赤い丸だけを目立たせない。必要な学習目標に応じて、誤答の選択肢も考えて作る。「0」の学習でも全問0にしない。
5. **図や並びと問いかけを分ける。** 数列・図形・比較対象は別の行、問いかけは次の行に表示する。意味のある改行は必ず保つ。タップ操作や音声案内も同じ内容を伝える。
6. **子どもが読める言葉にする。** ひらがな中心。学年に合わない漢字・難語・不自然な助詞・長い文を避け、必要なら音声で補う。文字を増やすより図と操作で教える。

## 必ず1問ごとに確認する4要素

| 項目 | 合格の目安 |
|---|---|
| 問題 | 何を見て何を答えるか、子ども一人で理解できる。絵・問題文・選択肢に矛盾がない |
| ヒント | 1段目は着目点、2段目は考える手順、3段目は答えに近づける具体例。最初から正答を言わない |
| 正答 | 正解が一意で、画面に表示された絵と正確に一致する。正答位置に偏りがない |
| 解説 | 「なぜその答えなのか」を実際の数字・図・順番を指して短く説明できる |

## 表現例

### 数字の順番

避ける：`1　2　□　□にはいるすうじは？`／`かくれた すうじは？`／`あいている ところに はいる すうじは？`

採用：

```text
1　2　□

□に はいる すうじは？
```

ヒント：「じゅんばんに よんでみよう」「□の まえと あとの すうじを みてね」

### 色と形（2つの条件）

避ける：「このなかの あかい まるは どれ？ 🔴 🔺 🔵」という同一行での露骨な誘導。

採用：1行目「① いろは あか」、2行目「② かたちは まる」、その下に「2つの おやくそくに あうのは どれ？」と3つの選択肢を置く。色だけ一致・形だけ一致する候補も用意する。

### 数字の0

避ける：○だけを表示して「空皿」を表したつもりになる／10問とも答えが0になる。

採用：同じお皿の絵を使って、0こ・1こ・2こを見比べる。数字0の読み方・意味も別の出題形式で確認する。

## レビューの順序

1. **問題の目的を確認**：ステージ名と求める力を一致させる
2. **子どもの画面を確認**：スマホとPCで文字・図形が重ならず、意味のある改行とタップ領域がある
3. **10問を通して確認**：同じ答え・同じ聞き方の連続、似すぎた出題、予測可能な正答を見つける
4. **ヒント・解説を確認**：その問題固有の図や数に結び付いているか確かめる
5. **人による承認**：文章表現・教育的適切性を確認するまで「確認済」「公開準備完了」と扱わない

自動テストは取りこぼしを減らすための仕組みであり、「幼児に必ず伝わる」ことを保証しない。
