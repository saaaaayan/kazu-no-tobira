# プレミアム権限

通常ステージは前の学年の通常50地点で次学年を解放する。既存セーブですでにEX経由で開いた島は引き続き利用できる。EX・ひみつ・賢者への入場はプレミアム権限と攻略条件の両方を使う。テストモードは攻略条件のみ省略し、記録を残さない。

開発ビルドはプラン切替を提供する。本番では開発用の切替や端末の購入フラグを使わない。EXPO_PUBLIC_ENTITLEMENT_URL に認証済みの HTTPS API を設定すると、アプリは認証セッションを添えて権限を照会する。API は購入事業者で検証した有効期限を基に、購入済みなら `{"premium":true,"expiresAt":"ISO 8601の時刻"}` を返す。未認証、失効、設定なし、通信失敗時は無料権限となる。API はユーザーをトークンや認証 Cookie から特定し、応答は個人用かつキャッシュ不可にする。Web は認証 Cookie と CORS を、ネイティブは認証機構とのトークン連携を構成する。

このリポジトリには認証サービス、購入アカウント、検証APIの本番環境はまだ接続していない。Pages やアプリに同梱されている既存の問題・解説データは直接取得できる。コンテンツそのものを購入者だけに配信するには、同梱・公開ディレクトリから除外し、購入を検証するサーバーから配信する作業が残る。
