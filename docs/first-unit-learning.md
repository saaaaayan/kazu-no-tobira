# 小1「10までの かず」：教材とステージの対応

[Issue #29](https://github.com/saaaaayan/kazu-no-tobira/issues/29) の初回教材。文部科学省 [小学校学習指導要領解説 算数編](https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf) の第1学年 A（1）を基に、一対一対応、個数と数字、0、数の順序と大小を扱う。単元配列の参考に [長野県総合教育センター](https://www.edu-ctr.pref.nagano.lg.jp/kjouhou/kyouka/data/sansuu/shougaku.htm) と [大阪府ワークブック](https://www.pref.osaka.lg.jp/o180080/shochugakko/shidou/workbookshougakkousa.html) を確認した。教材の文、図、例題、確認問題はこのアプリ用に作成した。

| ゲームの位置 | 既存ID | 問題バンクの内容 |
| --- | --- | --- |
| 1〜2 | e1.n04、e1.n05 | かずのじゅんばん。1〜10の数の道、前後・間、カードや列の位置。各100問。本教材の対応ステージ。 |
| 3〜8 | e1.forest、e1.n06〜n10 | 9までの足し算。 |
| 9〜13 | e1.n11〜n15 | 9までの引き算。 |
| 14〜19 | e1.bridge、e1.n16〜n20 | 10になる組合せ。既存バンクは足し算の式も使う。 |
| 20〜24 | e1.n21〜n25 | 20までの数。 |
| 25〜30 | e1.tower、e1.n26〜n30 | 繰り上がりのある足し算。 |
| 31〜65 | 従来どおり | 他の通常、EX、ひみつ。 |

旧版では最初の3地点の表示と単元表が一致しなかった。既存の教材・問題ID・ステージIDを変更せず、数の順序を扱う2地点を先頭へ移した。問題バンクは順序の応用を扱い、個数・0・大小の基本は教材の確認問題で確かめる。「いくつといくつ」「なんばんめ」を基礎から教える専用ページと、その段階に合う問題は次の制作範囲。

通常モードでは、対応する初回ステージに入るには確認問題4問の正答と、従来どおり前の地点のクリアが必要。すでにクリアした地点はすぐに再プレイできる。教材のページ位置、確認問題の結果、完了日時を既存の端末内セーブに追加する。ステージの回答・クリアとは別の項目で保存する。完了後の見直しやテストモードの学習は、通常モードの記録を書き換えない。

教材と全12学年の通常600ステージは無料。EX・ひみつ・賢者の島と詳しい解説などは将来の有料区分として定義した。今回の変更で課金やアクセス制限は取り入れない。
