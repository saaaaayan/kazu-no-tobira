# 各学年の導入教材

全12学年に1ページずつ、最初の通常ステージで扱う技能の教材を用意した。本数は12教材。各学年の残りの単元と、導入教材が扱わない部分は今後の範囲。

| 学年 | 導入教材 | 対応する学習指導要領の範囲 |
| --- | --- | --- |
| 小1 | 10までの数 | 数の構成と表し方 |
| 小2・小3・小4 | 位取り | 数の構成、表し方とまとまり |
| 小5 | 小数×整数 | 小数の乗法の基礎 |
| 小6 | 分数どうしの乗法 | 分数の乗法 |
| 中1 | 正負の数の加法 | A 数と式・正の数と負の数 |
| 中2 | 同類項 | A 数と式・文字を用いた式の計算 |
| 中3 | かっこの展開 | A 数と式・式の展開 |
| 高1 | 展開公式 | 数学Ⅰ・数と式 |
| 高2 | 多項式と恒等式の準備 | 数学Ⅱ・いろいろな式 |
| 高3 | 極限 | 数学Ⅲ・極限 |

表、例題と確認問題はオリジナル。関連する単元への前提関係を教材データに定義した。高校の科目配置は学校で異なるため、ゲーム内の学年は目安。
