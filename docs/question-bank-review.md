# 78,000問の制作状況と再開手順

[ステージ別進捗表](question-bank-progress.tsv) に全780ステージを記録する。「完成」は、公開した100問の自動検証と問題形式ごとの代表例確認を終えた範囲を指す。児童による使いやすさの評価や教育専門家による監修は未実施。従来の生成式しかないステージは、この制作案件では「未着手」とする。

## 確認した範囲

- 小1の最初の3ステージは、式、文章題、欠けた数、複数のまとまり、比較の各形式を見直した。「10をつくる」文章題では満杯から始まる6枠を差し替えた。正答履歴や出題順の参照を保つため、枠のIDは維持した。
- 箱と外の玉はそれぞれの場所に表示し、解説で移した玉と残りを見せる。移動数が正で、移動前後で総数が等しいことはテストで照合する。
- かずの じゅんばんの2ステージは、数の移動、両端を数えるかどうか、中央の数、列の位置の四形式を確認した。同じ区間でも求めるものや数える条件を明示する。文章題の図は、問題に必要な情報と答えが混ざらない場合に加える。

## 単元ごとの制作

「9までの たしざん」の通常5ステージ（`e1.n06`〜`e1.n10`）に500問を追加した。3つのまとまりの合計、目標との差、配った残り、まとまり同士の比較、増減、取り出した後の補充、2人の増加と合計の7形式を使う。候補を解法別に集め、条件が同じ候補は別ステージにも重ねて使わない。数字を選べる範囲は1〜9で、はじめから条件を満たす補充や増減の相殺を除く。

`scripts/early-addition-unit.mjs` に問題形式とステージ別の配分を置く。`scripts/validate-early-addition.mjs` は生成器の答えを使わず、問題文の数字を読んで解法別に再計算する。ヒント3の数値、図、途中式、重複も検査する。`pnpm bank:build` は全バンク、Web・ネイティブ用登録、進捗表を同時に更新する。`pnpm bank:check` は生成結果と保存内容を比較し、差異があれば終了する。この検査は `pnpm test` にも含める。

「9までの ひきざん」の通常5ステージ（`e1.n11`〜`e1.n15`）に500問を追加した。取り出した残り、2回の減少、最初の数の復元、2回目に減った数、減少後の比較、箱同士の移動、同数への調整、比較からの復元の8形式を使う。独立検査で問題文の条件と解答、図、ヒント、途中式を確認する。

「10をつくろう」の通常5ステージ（`e1.n16`〜`e1.n20`）に500問を追加した。10までの不足を比べる、取り出して補う、別の箱から必要分を使う、取り置いた残りを使う、同じ数を足した2箱を10にする、10を超えた分を引く、玉を移した後に不足を比べる、の7形式を使う。独立検査で初期条件、正答、ヒント、式、図、単元内で重複しないことを確認する。

「20までの かず」の通常5ステージ（`e1.n21`〜`e1.n25`）に500問を追加した。10のまとまりとばら、数の移動、両端を除いた枚数、中央、近い数、往復、並べ替えを出題する。問題文の数値から正答を再計算し、図、ヒント、途中式、単元内重複を検証する。カードを使う問題の解説図のラベルは「とりだした ぶん」に統一した。

## 再開位置

小1の `e1.n26`「くりあがりの たしざん・はじめの一歩」から、通常5ステージの単元バッチを設計する。`e1.x02`（9までのたしざんのEX）は通常問題の再配分で埋めず、EX用の応用形式を追加する。各単元の5段階とEXで、出題の目的と解法を設計してから100問の集合を作る。低学年では、同一の題材を語句や数だけで増やさず、式の穴埋め、数量の比較、具体物や文章から式を作る課題を配分する。小1の残り40ステージを先に進める。

1. 学年・単元に合う問題形式を設計し、既存バンクに追加する。
2. `node scripts/build-question-banks.mjs` で配信データと進捗表を再生成する。進捗表の完成判定は、独立検証と代表例レビューを済ませて登録したバンクに適用する。
3. 問題文から独立に正答を再計算するテスト、実質重複、問題文・図・ヒント・途中式の整合性を確認する。
4. AGENTS.mdに従い、テスト・型チェック・Webビルドと公開確認を行う。
