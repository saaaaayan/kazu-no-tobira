# 問題制作の再開地点

全16島・1,040ステージ・104,000問の制作と教材審査は未完成です。実登録数と不足数は [共有可能な制作状況](question-production-checkpoint.json) と、公開リポジトリの [バンク台帳](question-production-progress.json) を参照してください。非公開原稿を含む詳細は `question-drafts/report/question-production-progress.json` に保存します。登録済みの専用バンクや既存セーブのIDは維持しています。

- 制作は幼児の島の `preschool.n01`（ものを かぞえる）の未完成分から再開します。初回の問題は専用審査DBに取り込む `question-drafts/` に保存しています。数唱だけでなく、タップ順が違っても個数は同じ、未タップの物から数える、重なりや配置に惑わされず対応づける活動を設計します。図、操作、段階的ヒントと解説、独立した正答検証を揃えてから登録します。
- 同時に着手した小1 `e1.n41`、賢者 `sage.n04`、覇王 `champion.n01`、宇宙 `cosmos.n01` の不足も継続します。宇宙は集合・写像・論理の単元教材を作ってから出題に接続します。
- 構造類似候補は監査結果から意図した反復か確認し、根拠を記録します。自動検査と教材レビューは別の工程です。
- 作問データを更新したら `pnpm bank:audit --drafts` でPC内の詳細台帳を更新します。公開リポジトリに送るのは件数やステージIDなどの集計だけです。`question-drafts/` に原稿と独立検証を置き、PC内の非公開バックアップに含めてください。
- 確認用の中央審査DBは [審査サーバーの操作手順](question-review-server.md) で再開します。取得時点のDB状態を使用し、既存の端末内記録を公開判定に流用しません。
