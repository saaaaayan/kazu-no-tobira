全16島・1,040ステージ・104,000問の制作と教材審査は未完成です。実登録数と不足数は [問題制作台帳](question-production-progress.json) を参照してください。登録済みの専用バンクや既存セーブのIDは維持しています。

- 作問データを更新したら `pnpm bank:build` と `pnpm bank:audit --update` を実行し、生成された台帳ごとコミットします。
- 審査DBの状態と公開準備完了件数は、中央審査のスナップショットが取れるまで端末内の記録から推定しません。
